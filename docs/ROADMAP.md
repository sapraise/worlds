# Implementation order

## Local alpha: 20–30 human hours target

1. Inspect the repo and authorised Glob materials; select one visual pipeline and record constraints (2h).
2. Prove source discovery, validated plans, a real MCP update, and two local clients (5h). Report integration blockers precisely.
3. Build one readable scene and shared UI foundations: movement/collision, roster, inspector, task/artifact views, direct list access (6h).
4. Make source → AgentPlan → WorldPlan → reviewed build usable; persist layout and preserve IDs (4h).
5. Add first original character treatment, a small design explorer, local landing and substantial world-gallery concepts (4h).
6. Verify clean local install, meaningful failure/security cases, two-client reconnect, and record a short demo and limits (5h).
7. Keep 4h buffer. At 20h reduce art/extra routes before dropping truthful state or the central workflow.

These are estimates, not a guarantee that a full product, all integrations, four production worlds and a complete 3D library fit this budget.

## System expansion

Complete the Glob-to-Worlds depth matrix. Add the production character/rig/pose library, richer world kits, meaningful remix tools, improved onboarding and a tested Nebula integration. Validate every new surface against the same shared contracts. One system, several settings.

## Later public launch

Only after local acceptance and a separate go-live decision: choose deployment and domain, implement hosted authentication and tenancy, verify private/public data separation, run a small pilot, publish a usable alpha, then prepare Product Hunt and MCP directory submissions. A public source repository is not a public deployed application.

MCP directory eligibility requires an actual protocol-compatible server and accurate metadata. Registry listings do not host the service. No launch channel or hosting provider is configured by this roadmap.
